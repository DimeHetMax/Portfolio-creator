# Portfolio Creator

Portfolio Creator is a responsive landing page for a product designer portfolio. The website presents a modern personal brand with clear sections for services, selected projects, blog posts, professional background, testimonials, FAQ, and contact information.

The page is built with semantic HTML and modular CSS. Its design is based on the following Figma layout:

https://www.figma.com/design/FMFODrqDfClG7GQGGd89qv/Portfolio-Creator?node-id=0-1&p=f&t=uH7e47DrSJyZ7LSt-0

## Website Overview

The website includes:

- A header with logo and navigation links
- A hero section introducing the designer and call-to-action buttons
- A trusted-by section with partner or client logos
- A services section describing design skills and tools
- A projects showcase with featured case studies
- A blog section with recent articles
- A product designer section with personal introduction and gallery
- Education and work experience blocks
- A testimonials section
- A frequently asked questions section
- A footer with contact details and additional navigation

## Styling Structure

The CSS is split into smaller files for easier maintenance:

- `css/main.css` imports all other stylesheets
- `css/reset.css` contains element resets
- `css/base.css` defines variables, typography, buttons, and shared utility styles
- `css/layout.css` contains layout helpers such as the main container
- `css/sections.css` contains styles for page sections
- `css/responsive.css` contains tablet and mobile breakpoints

## Purpose

This project is a front-end practice layout focused on:

- Building a clean multi-section landing page
- Practicing responsive design for desktop, tablet, and mobile
- Organizing CSS into a modular file structure
